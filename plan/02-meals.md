# 02 — 每日飲食詳細規劃

一日 7 餐增肌組合，全日蛋白質 223g、熱量 3000 kcal。

---

## 🌅 餐 1：早餐 (08:30) — 增肌啟動

**蛋白質：42g**

```
✓ 半個雞胸（120g）— 烚或煎
✓ 菜心一份（或西蘭花、菠菜）
✓ 麥皮 1 碗（傳統大片，唔好即食）
✓ 加 2 隻水煮蛋（重要升級！）
✓ 1 杯黑咖啡
✓ 飲 500ml 溫水
```

**輪流變化**：
- 雞胸可換：火雞胸、煙三文魚、雞蛋餅
- 麥皮可換：藜麥、糙米粥
- 菜心可換：芥蘭、菠菜、莧菜、白菜

---

## ☕ 餐 2：上午茶 (10:30) — 防分解

**蛋白質：25g**

```
✓ Whey Protein 1 scoop（25g 蛋白）— 凍水或低脂牛奶
✓ 一把杏仁/腰果（30g）
```

**替代選項**：
- 2 隻水煮蛋 + 1 個蘋果
- 雞蛋三文治（全麥麵包、唔加芝士）
- 100g 雞胸肉粒 + 青瓜

---

## 🍱 餐 3：午餐 (12:30) — 訓練前能量

**蛋白質：35g | 碳水：適中**

同媽媽食嘅建議組合（加拿大期間：同太太）：

| 蛋白質主菜（揀 1 樣）| 蛋白質量 |
|---|---|
| 白切雞 / 蒸雞 / 豉油雞 | 35-40g |
| 蒸魚（鱸魚、桂花魚、東星斑）| 35g |
| 蝦仁炒蛋 / 白灼蝦 | 25-30g |
| 紅燒瘦牛肉 / 蕃茄牛肉 | 30-35g |
| 釀豆腐 / 麻婆豆腐 | 25g |

**配合**：
```
✓ 紅米/黑米飯 半碗（150g 熟）
✓ 蔬菜 2 樣（菜心、西蘭花、節瓜、絲瓜）
✓ 湯 1 碗（清湯為主）
```

**避免**：
- ❌ 糖醋排骨、咕嚕肉（高糖）
- ❌ 蜜汁叉燒（高糖醃製）
- ❌ 大量白飯
- ❌ 油炸嘢

---

## 💪 餐 4：訓練後黃金餐 (15:00) — 最重要嘅一餐！

**蛋白質：35g | 碳水：高（補肝糖）**

```
✓ Whey Protein 1 大 scoop（30-35g）— 凍水 + 1 條香蕉打成 shake
✓ 1-2 條香蕉
✓ Creatine 5g
✓ 大量水（500ml+）
```

⚠️ **訓練後 30 分鐘內必飲**——增肌 #1 規則。Calendar 會 14:55 提醒。

---

## 🍓 餐 5：下午茶 (16:30) — 鞏固恢復

**蛋白質：18g**

```
✓ 希臘乳酪 1 杯（FAGE / Total，200g）
✓ 一把莓類（藍莓、士多啤梨）
✓ 1 茶匙蜂蜜（可選）
✓ 桑葉決明子茶 1 杯
```

---

## 🍳 餐 6：晚餐 (19:00) — 增肌主餐

**蛋白質：50g | 碳水：訓練日中等、休息日低**

蛋白質選擇（揀 1 樣，200g）：

| 食物 | 點煮 | 蛋白質 |
|---|---|---|
| 雞胸/雞髀 | 香煎、烤、烚 | 50g |
| 三文魚 / 鯇魚 / 鱸魚 | 蒸、煎 | 45g |
| 牛眼肉 / 西冷 | 煎（少油）| 45g |
| 豬里脊 / 豬扒 | 香煎 | 45g |
| 豆腐 + 雞蛋（素食日）| 各 100g | 35g |

**訓練日配合**：
```
✓ 紅米/黑米飯 1 碗
✓ 蔬菜 2 樣（大份）
✓ 1 湯匙橄欖油 / 半個牛油果
```

**休息日配合**：
```
✓ 紅米/黑米飯 半碗
✓ 蔬菜 3 樣（更大份）
✓ 1 湯匙橄欖油
```

---

## 🥛 餐 7：夜宵 (21:00) — 抗夜間分解

**蛋白質：18-25g**

```
✓ Casein Protein 1 scoop（瞓覺時慢釋放）— 凍水或低脂奶搖勻
✓ 或希臘乳酪 1 杯
✓ 或 Cottage Cheese 100g
```

⚠️ **唔可以食碳水**——保持瞓覺血糖低。

---

## 📊 全日總結

| 時間 | 餐次 | 蛋白質 | 大約熱量 |
|---|---|---|---|
| 08:30 | 早餐 | 42g | 600 kcal |
| 10:30 | 上午茶 | 25g | 300 kcal |
| 12:30 | 午餐 | 35g | 600 kcal |
| 15:00 | 訓練後 | 35g | 350 kcal |
| 16:30 | 下午茶 | 18g | 250 kcal |
| 19:00 | 晚餐 | 50g | 700 kcal |
| 21:00 | 夜宵 | 18g | 200 kcal |
| **總共** | | **223g** | **3000 kcal** |

**目標達成**：
- 蛋白質 130g+（達 223g）
- 熱量 2,800 kcal+（達 3000 kcal，增肌盈餘）
- 碳水：訓練日 250-300g、休息日 150g
